# 真实持仓顾问：并行部署预览

本包是可并行部署的开发预览，不是可用于交易的最终版本。新服务绑定 `GUANPAN_ADVISOR_PORT`（默认 8786）、新 Compose 项目 `guanpan-advisor` 和新 named volume `guanpan_advisor_data`；代码直接构建进新镜像，不挂载旧版源码；旧服务 30001 与数据库保持独立。

## 已添加

- 新增只读 `GET /v1/advisor/inventory`，从 NAS 真实账本列出非零持仓，统计 NAS 分时档案的日期范围及每日至少 200 个不重复交易时段分钟点的天数。60 天与 200 点仅是预设覆盖筛选标准，不代表完整性、有效性或统计显著性。
- 新增需逐次确认的 `POST /v1/advisor/analyze`。用近 60 个有效交易日的均值幅度、日内路径效率、报价时效、带来源的交易规则、分批现金预算与可卖份额筛查 T+0 做 T / T+1 网格 / 不交易；计划列出限价、份额、手续费假设、双边都成交时的净额、按当前持仓份额折算的降本、依据、风险和失效条件。
- 在线 AI 使用现有 NAS DeepSeek key，新闻标题由 Google News RSS 获取并附日期/来源/链接；AI 提示明确不得把标题当已核实事实，也不能编造计算计划。缺 key、RSS、行情或规则时保留缺口并降级。
- NAS 行情采集器同时包含真实持仓，不更改已有自选/档案追踪列表。无回溯下载能力；历史覆盖始于已有档案和实际采集。
- 网页和 iOS 现有私人顾问页面增加检查入口。iOS 已有的决策历史保存分析快照。顾问接口不写账本、不操作模拟账户、不下单。原有接口与功能保留。

## 已验证

- NAS Python/HTTP 自动测试：88 项通过。
- Python 语法检查、网页 JavaScript 语法检查和 Docker Compose 配置解析通过。
- Docker 镜像未能构建：当前工作站的 Docker Desktop Linux 引擎未运行。没有对 NAS 实际部署。

## 未完成，不能用于交易

- 交易分类采用确定性历史筛选启发式，阈值尚未通过策略研究和纸上交易验证。
- 尚未检查交易日历、停牌、分钟采集内部缺口或分时/复权一致性；可卖份额按 NAS 账本及本日买入流水估算，未向券商核实。规则来源与核验时间来自 iOS 本地资料，未向交易所/券商在线复查。行情时效门槛已实现，但不等同于交易所级行情质量。
- 新增 iOS 代码尚未在 Xcode 编译，也未在模拟器、真机和真实 NAS 验证。网页未做浏览器端到端测试。不能保证部署兼容。
- 旧模拟账户及网格行为保留，遵照用户要求不改变现有功能；新增检查不使用模拟资金。

## 安全

不要将本开发预览用于实盘交易；不要直接覆盖原部署或数据库。新端口的数据卷初始为空。部署前确认 8786 可用并在新服务独立测试。原服务没有应用鉴权，按现有设计仅适用于受信任局域网或 VPN；新增接口返回真实持仓，不应暴露公网。
